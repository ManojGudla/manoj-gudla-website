# Dashboard guide

Sign in at **yourdomain.com/admin**. Everything you save goes live on the website immediately — no rebuild, no code.

## How publishing works

Every item (project, video, skill, goal…) is either **Draft** (only you can see it) or **Published** (on the website).

| Button | What happens |
| --- | --- |
| **Save as draft** / **Save draft** | Saves; stays hidden from visitors |
| **Publish** | Saves and puts it on the website |
| **Update** | Saves a published item; it stays published |
| **Unpublish** | Takes it off the website but keeps it |
| **Preview on site** | Opens the website showing drafts too, with a blue bar on top. "Exit preview" turns it off. Only you can see drafts |
| ↑ ↓ in a list | Changes the order on the website |
| **Delete** | Asks to confirm, then removes it permanently. Unpublish instead if you might want it back |

New items start as drafts. Nothing reaches visitors until you press Publish.

## First things to do

The **Overview** page lists what needs attention. In order:

1. **Profile → Portrait photograph** — upload a real photo. Until then the homepage shows an elegant monogram frame.
2. **Profile → Résumé (PDF)** — the "Download résumé" button appears on the Journey page once this is set. Until then, the button asks visitors to request it through the contact form.
3. **Experience** — two internships (HMI, Adhoc Network Tech) are saved as drafts. Check the dates, add responsibilities if you want, and publish. The TCS entry says you work on an AI & ML project without naming the client — add more only if your employer allows it.
4. **Education** — add the year you completed your MCA in "End / year completed".
5. **Audience statistics** — your YouTube, Instagram and views figures are saved as **drafts**. Check them against YouTube Studio and Instagram Insights, update the numbers and dates, then publish. They show as "Self-reported" unless you choose "Verified" and enter the date you checked.
6. **Creator content** — add your best videos and reels by pasting their links. YouTube links get a thumbnail automatically.
7. **Settings → Social sharing image** — optional; a branded image is generated automatically.

Tips:

- **Paragraphs:** leave a blank line between them.
- **Lists** (features, technologies, responsibilities): one item per line.
- **Web address** of a project: lowercase words with hyphens, e.g. `my-new-app` → `/projects/my-new-app`.
- **Skill levels** only appear publicly when you tick "Show proficiency publicly".
- **Feature on the homepage** (projects) and **Featured** (creator content) control what the homepage shows.
- Text fields show a character count; the limit keeps layouts tidy.

## Resources and "comment for the link"

**Resource library** holds every tool, course and link shown on the Resources page.
- **Add:** Resource library → **Add resource** → name, link, topic, price → **Publish**.
- **Hide or remove:** **Unpublish** (in the list or on the item) or **Delete**.
- Fixing a link here fixes it in every pack that uses it.

**Resource packs**: one per video.
1. Resource packs → **New resource pack**.
2. Title, a short **code** (e.g. `ai-tools` → `yoursite/r/ai-tools`), the comment **keyword** (only you see it), and the video link.
3. **Save as draft**. At the bottom, **Add a resource**: pick from your library, or type a new name and link (it's added to the library too). Add an optional note like "used for the thumbnail".
4. **Publish**, then reply to commenters with `yoursite/r/ai-tools`.
5. Optional: in **Creator content**, add the video and choose its pack. The video card and the homepage then show "Resources from this video".

## Work with me

**Services** are drafts at first. The "Work with me" page and its menu link appear as soon as one is published. "Start a conversation" opens the contact form with the right topic selected.

## Homepage "Now" strip

Profile → **Now — building / learning / creating**. Leave a line empty to hide it. Your latest video appears there automatically.

## Photos and files

Upload from **Media library**, or straight from any image field with **Choose or upload**.

- Accepted: JPEG, PNG, WebP, AVIF up to 20 MB; PDF up to 10 MB. iPhone HEIC photos: export as JPEG first.
- Every image is resized (max 2400 px), converted to WebP for speed, and **location data is removed** automatically.
- Always fill in **Alt text** — a short description of the photo. It helps people using screen readers and helps Google.
- **Replace** a file in the Media library and every page using it updates.
- **Deleting** a file asks first; pages using it fall back to no image.

## Enquiries

Messages from the contact form arrive in **Enquiries** (a blue count shows new ones). They are private — never shown on the website.

- Opening a message marks it **Read**. You can set **New**, **Read**, **Responded** or **Archived**, change its type, and keep private notes.
- **Reply by email** opens your email app with the subject filled in.
- The Inbox hides archived messages; use the tabs to see them.
- To delete a message, open it → **Delete enquiry** → confirm.

## Truthfulness rules built in

The site is designed to stay credible:

- Audience figures are labelled "Self-reported" unless verified, and always show when they were last updated.
- Personal highlights are labelled as personal highlights, separate from external awards.
- Vision items are always labelled as goals, not achievements.
- Roadmap items on projects are labelled as planned, not released.

Only add awards, certificates and numbers you can back up.
